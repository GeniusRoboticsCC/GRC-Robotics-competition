Part 2

Unbox and power-on test

10 minutes

Static electricity can damage the board. Before you open the packaging, touch something metal and earthed, such as a metal tap or the metal case of a plugged-in PC. Work on a wooden or plastic table, not on carpet and not on a metal surface.

  1. Open the packaging. The board usually comes in a silver or pink anti-static bag. It's sometimes pushed into a piece of black foam, and sometimes there are loose pin strips. Keep the bag so you can store the board in it later.
  2. Take the board out of the foam if it's in some. Pull it out slowly and straight, rocking it gently from end to end, so the pins don't bend.

    Never plug in the board while its pins are in the black foam. The foam conducts electricity and can short-circuit the pins.

  3. Hold the board by its edges. Avoid touching the chips and the metal cover.
  4. Check the pins. Look at the board from the side. Are there two rows of metal pins sticking out underneath, or only empty holes?

    Only empty holes, with two loose pin strips in the bag? That's normal for the LOLIN32. Ask someone with a soldering iron to solder them on, with the long pins pointing down (away from the metal cover). You can do Parts 3–7 first, because they only use the USB socket. The pins are needed from Part 8.

First power-on test

This quick test shows the board and cable work before you install anything. Nothing is wired to the board yet.

  1. Plug the USB cable into the board, then into the PC.
  2. Listen for the Windows "device connected" sound. This is the main check.
  3. Look at the LEDs. The LOLIN32 has no power light. Its small CHG LED may light up or flicker, which is normal when no battery is attached. The blue LED may blink if the board has a factory test program. Seeing neither is also fine.

The Windows sound played: board and cable are fine. Carry on with Part 3.

No sound: try another USB socket on the PC, then another cable. The cable probably only charges, so swap it for a data cable before Part 5.

Part 3

Get to know the board

5 minutes

Find each numbered part on your own board, and fill in the box at the bottom right. You need these details later.

  • 1Micro‑USB socket. Power and programming.
  • 2RESET button. Restarts the board. The LOLIN32 has no BOOT button; the test wire does that job.
  • 3Blue LED (pin 5). Our program turns it on when the board is connected to Supabase.
  • 4CHG LED. Battery charging light. It may light or flicker when no battery is attached, which is normal.
  • 5USB chip, CP2102. It needs the Silicon Labs CP210x driver (Part 5).
  • 6ESP‑32 module under the metal cover. This is the computer.
  • 7Wi‑Fi antenna. Keep this end clear of metal.
  • 8White battery plug. Only for a 3.7 V LiPo battery. Never plug the AA servo battery pack in here.
  • PThe pins you'll use, all on the right: 18 (servo signal), a GND (ground), and 0 with the GND below it for the test wire.

Part 4

Install the Arduino software

20–40 minutes, once per PC
needs internet

A. Install Arduino IDE 2

  1. On the PC, open arduino.cc/en/software in a web browser.
  2. Download the Windows installer, called Windows · Win 10 and newer, 64 bits. If a donation page appears, click Just Download.
  3. Run the downloaded file. Click I Agree, keep the default options, click Install, then Finish with "Run Arduino IDE" ticked.
  4. Answer the first-start questions:
    • Windows Firewall asks about network access: click Allow.
    • Windows asks "Would you like to install this device software?": click Install. These are USB drivers.
    • Arduino offers updates: it's safe to install or skip them. No extra libraries are needed for this project.

B. Add ESP32 support

  1. Open the Boards Manager: click the second icon in the left sidebar (number 5 in the picture below), or use Tools › Board › Boards Manager…
  2. Type esp32 in the search box.
  3. Find "esp32 by Espressif Systems" and click Install. The newest version is a 1.9 GB download, so use internet with plenty of data, not a phone hotspot. On slow internet, pick 2.0.17 in the version list next to Install first (830 MB). The program is written to work with both.

    Pick "esp32 by Espressif Systems", not "Arduino ESP32 Boards by Arduino", which is for a different board.

  4. Watch the Output panel at the bottom. It should show Downloading… lines with progress. If nothing changes for 5 minutes, close Arduino completely, reopen it and click Install again. When it's finished, the label "INSTALLED" appears with a version number.

"esp32 by Espressif Systems" isn't in the list? Open File › Preferences…, paste this into Additional boards manager URLs, click OK and search again:
https://espressif.github.io/arduino-esp32/package_esp32_index.json

Part 5

Connect the board to the PC

5–15 minutes
  1. Install the USB driver first. The LOLIN32's USB chip is a CP2102, and Windows often doesn't install its driver by itself. Without it, the board won't get a COM port.
    1. On silabs.com, search for CP210x USB to UART Bridge VCP Drivers. On the Downloads tab, download CP210x Universal Windows Driver. It's a ZIP file.
    2. Right-click the ZIP and choose Extract All.
    3. In the extracted folder, right-click silabser.inf and choose Install. On Windows 11, click Show more options first. Accept the prompts.
  2. Plug the ESP32 into the PC with the data cable. Plug it into the PC itself, not a USB hub, if you can.
  3. Check Device Manager: right-click the Start button, click Device Manager, then open Ports (COM & LPT). You should see Silicon Labs CP210x USB to UART Bridge (COM…). The COM number in brackets is your board.
  4. Choose the board and port in Arduino: click the board selector at the top (3), then Select other board and port…. Type ESP32 Dev Module in the left box and click it (WEMOS LOLIN32 also works), click your COM port on the right, then OK.

Part 7

Put the program on the ESP32

15 minutes

A. Get the program files

  • On the organiser's PC: they're in Desktop\GRC Tournament\esp32\ball_release\
  • On another PC: open the GitHub repository, click Code › Download ZIP, then right-click the ZIP and choose Extract All. Open GRC Tournament\esp32\ball_release\

Keep the folder name ball_release. Arduino needs the folder to have the same name as the .ino file inside it.

B. Open it and fill in your details

  1. Double-click ball_release.ino. It opens in Arduino. You can also use File › Open…
  2. Click the secrets.h tab (6) and fill in the four lines between the quote marks: 
    // The Wi-Fi it will use at the venue (2.4 GHz)
#define WIFI_SSID       "GRC-Hotspot"          // exact name, capitals matter
#define WIFI_PASSWORD   "your-password-here"

// Optional backup network, e.g. a second phone's hotspot ("" if none)
#define WIFI_SSID_2     ""
#define WIFI_PASSWORD_2 ""

// The token from Part 6
#define DEVICE_TOKEN    "3f9a1c…the long code…"
    Keep the quote marks " and change only the text between them.

    No secrets.h tab? Click the ⋯ button at the right end of the tabs, then New Tab, and name it secrets.h. Copy everything from the secrets.example.h tab into it, then fill it in.

  3. Save with Ctrl+S.

Make the hotspot 2.4 GHz, because the ESP32 can't see 5 GHz Wi‑Fi:

  • iPhone: go to Settings › Personal Hotspot and turn on Maximise Compatibility.
  • Android: in the Hotspot settings, set the AP band to 2.4 GHz. Also turn off "Turn off hotspot automatically" if your phone has it.

Never upload secrets.h to GitHub, especially through the GitHub website. It holds your Wi‑Fi password and the token.

C. Upload

  1. Check the top bar (3) shows ESP32 Dev Module and your COM port.
  2. Click Upload (2, the → arrow). The first time, "Compiling sketch…" takes 1–3 minutes.
  3. Watch the Output panel (7). It shows Connecting...., then Writing at … (10 %) … (100 %), and finally Hard resetting via RTS pin.... That last line means it's done.

    Stuck on Connecting……, or "Failed to connect"? The LOLIN32 has no BOOT button, so use the test wire instead. Connect pin 0 to the GND pin below it, press RESET, click Upload again, and remove the wire once the percentages start. Press RESET when it's finished.

    Red error text while "Compiling"? Take a photo or copy the first red lines and send them to whoever set up the website. The most common cause is a missing quote mark " in secrets.h.

D. Check that it works

  1. Open the Serial Monitor (4, top right). In its bar, set the speed to 115200 baud.
  2. Press RESET on the board once to restart it. Within about 10 seconds you should see: 
    GRC ball release starting
Connecting to Wi-Fi "GRC-Hotspot"...
Wi-Fi connected to "GRC-Hotspot", signal -52 dBm
Connected to Supabase. Waiting for the Release button (last release was #0).

Done when: the blue LED next to RESET stays on, and the staff page's Ball release panel shows ● Dropper online. If the LED does the opposite (on while offline), change LED_ACTIVE_LOW near the top of ball_release.ino and upload again.

Part 8, continued

Wiring tips and checks

Check before switching on

Servo wire colours

Brown or blackGround (−)
Red (middle wire)Power (+)
Orange, yellow or whiteSignal

REV Smart Robot Servo: black = −, red = +, white = signal.

How a breadboard joins wires

  • The long + and − rows along the edge (the rails) are each joined all the way along.
  • On some breadboards the rails are split in the middle: look for a gap in the red and blue lines. If yours has a gap, keep all the + and − wires on the same half.
  • Each short column of 5 holes (rows a–e) is joined. The groove in the middle separates a–e from f–j.

Practical tips

  • Servo plug: push one end of each male‑to‑male jumper into the three holes of the servo's plug.
  • Battery leads are soft, stranded wire. Twist the bare ends tightly so they push firmly into the holes. If they're too short or floppy, ask someone to solder on header pins, or use a holder with a plug.
  • A holder with an on/off switch gives you a servo power switch, which is handy for setup and at the field.
  • The ESP32 doesn't go in the breadboard. It's too wide. Let it sit beside the breadboard on the jumper wires.

Never connect the battery or the servo's red wire to any ESP32 pin, including 3V and 5V, or to the board's white battery plug. The ESP32 gets its power only from USB. The two meet only at GND.

Wire 7 (GND to GND) is required. Without it the servo twitches randomly or doesn't move at all.

Check before switching on

  • Battery red and servo red are both in the + rail, and nothing else is.
  • Battery black, servo brown and ESP32 GND are all in the − rail.
  • Servo signal and ESP32 pin 18 are in the same 5‑hole column, on the same side of the groove.
  • No bare wire ends are touching each other.
  • Nothing is connected to the ESP32's 3V or 5V pins, or to its white battery plug.

All ticked? Put the battery back in, or switch the holder on, then plug in the ESP32's USB. The servo moves once to its closed position. That's normal.

Part 9

Fit the servo and set the angles

15–30 minutes
needs the PC for changes

Keep fingers clear of the gate whenever the servo has power. It can move suddenly, for example when the board restarts.

  1. Switch on the servo battery, then plug the ESP32 into the PC (the PC is needed to change the angles). The servo turns to the closed position and stays there.
  2. Fit the arm. If it's already on, unscrew it and pull it off. Push the arm onto the shaft at the angle where it shuts the gate, then put the small screw back in.
  3. Test with the test wire. Push one end of the female‑to‑female jumper onto pin 0 and leave it there. To test, push the other end onto the GND pin just below pin 0 for a second, then pull it off. The gate should open for 1.5 seconds and close again. The Serial Monitor shows Opening the gate (test on pin 0). This works even without Wi‑Fi.

    Don't leave pin 0 connected to GND while plugging in or pressing RESET. That starts the board in programming mode, so it waits instead of running. Pull the wire off GND and press RESET to fix it.

  4. Adjust if needed. On the PC, open ball_release.ino. Change these lines near the top, then Upload again (Part 7C) and repeat step 3: 
    const int CLOSED_ANGLE = 0;               // gate shut (0 to 180)
const int OPEN_ANGLE = 90;                // gate open (0 to 180)
const unsigned long HOLD_OPEN_MS = 1500;  // how long it stays open (1500 = 1.5 s)
What you seeChange
Opens the wrong waySwap the numbers, for example CLOSED_ANGLE = 90 and OPEN_ANGLE = 0.
Doesn't open far enoughMove OPEN_ANGLE further from CLOSED_ANGLE, for example 90 → 110.
Servo buzzes or strains when closedIt's pushing against something. Move CLOSED_ANGLE 5–10 degrees towards OPEN_ANGLE.
Some balls stay behindIncrease HOLD_OPEN_MS, for example to 2500.
Arm is roughly right but a bit offFine-tune the angle a few degrees at a time, or re-fit the arm one notch over.

Part 10

Test from the staff page

10 minutes
  1. On the phone staff will use on the day, sign in to the staff page and open the Score tab.
  2. Check the Ball release panel shows ● Dropper online and the Wi‑Fi strength. "Strong" and "OK" are both fine.
  3. Load a few balls behind the closed gate.
  4. Press ⬇ Release balls, then OK.
  5. Watch the panel and the gate: the panel shows ● Releasing… waiting for the dropper, the gate opens and closes, and then the panel shows ● Released ✓ Match N.
  6. Repeat 5 times with real balls, including from a second staff phone.
  7. Test a Wi‑Fi drop: turn the hotspot off. Within about 15 seconds the panel shows ● Dropper offline. Turn it back on: within about 30 seconds it's back to ● Dropper online.

What the panel can show

PanelMeaning and what to do
● Dropper onlineReady. The ESP32 checked in within the last 10 seconds.
● Releasing… waiting for the dropperThe press was received. The button is locked until the dropper confirms, usually 2–3 seconds.
● Released ✓ Match NThe gate opened and closed.
● Not confirmed by the dropperNo confirmation within 20 seconds. Check power, the LED and the hotspot, then press again.
● Dropper offlineThe ESP32 isn't connected: no power, no Wi‑Fi, or the hotspot is off.
● Not set up yetThe database step (Part 6) is missing.

Built-in safety

  • No surprise drops: after a power cut or restart, the ESP32 never repeats an old release.
  • No late drops: it ignores any release more than 20 seconds old, for example if the Wi‑Fi dropped for a while.
  • No double drops: two presses within 3 seconds, even from two phones, count as one.
  • A record of every release: each one is logged with the match number and the staff member who pressed it.
Part 11

Install it on the field

30 minutes
day before the event
  1. Mount the servo firmly with screws, cable ties or strong double-sided tape, so it can't twist when the gate opens. Test again with the test wire after mounting.
  2. Put the ESP32 and breadboard in a small plastic box, not a metal one, which blocks Wi‑Fi. Leave a gap or hole for the wires. Keep it away from the robots, the balls and people's feet.
  3. Secure every wire. Tape the jumper wires to the breadboard and box so a tug can't pull them out. Loose jumpers are the most common failure at events.
  4. Power for the ESP32: a phone wall charger is best. If you use a power bank, charge it fully and test it for 30 minutes. Some power banks switch off by themselves when the load is small.
  5. Hotspot phone: keep it within about 10 m of the box, on a charger, with auto-off disabled. If the panel shows weak Wi‑Fi, move the phone closer.
  6. Batteries: put fresh AAs in on the morning of the event and keep a spare set in the box.
  7. Label the box "Ball release – please don't touch".
  8. Full rehearsal: run a complete fake match from the staff phone: start the clock, release the balls, and check ● Released ✓ appears.

Event-day checklist

Saturday 14 November

30 minutes before doors open

  • Hotspot on, on 2.4 GHz (Maximise Compatibility), phone charging
  • Fresh AA batteries in, servo battery switched on
  • ESP32 plugged in, and the blue LED on within about 10 seconds
  • Staff page shows Dropper online with Strong or OK Wi‑Fi
  • Empty test release from the staff page: the gate opens and closes, and the panel shows Released ✓
  • All wires taped down, box closed and labelled
  • Balls loaded with the gate closed

Every match

  • Correct match on the display
  • At the start signal, press ⬇ Release balls and confirm
  • The panel shows Released ✓ Match N
  • Reload the balls for the next match

If something goes wrong mid-event

  1. Don't hold up the match. Use the backup: touch the test wire from pin 0 to GND, or drop the balls by hand.
  2. Look at the blue LED. If it's off, check the ESP32's power and the hotspot.
  3. Servo doesn't move but the panel shows Released ✓? Check the servo battery and its wires.
  4. Still stuck? Unplug the ESP32's USB for 5 seconds, then plug it back in. It reconnects within about 10 seconds and won't drop anything by itself.

After the event

  • Unplug the ESP32 and take the batteries out
  • Store the board in its anti-static bag

Make a new device token

Do this if the token was shared by accident. Run these two lines in the Supabase SQL Editor, put the new token in secrets.h, and upload again:

update public.field_devices set token = replace(gen_random_uuid()::text, '-', '') where name = 'dropper';
select token from public.field_devices where name = 'dropper';
